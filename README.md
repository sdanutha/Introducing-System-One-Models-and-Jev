# Jev and System One

A simple introduction to Jev, with hands-on guides for learning its Noul, Choice, and Score question types.

## Files

- `Introducing-Jev-System-One.html` — 11-slide presentation. Open it in a web browser; use the arrow keys or on-screen buttons to navigate.
- `0-Jev-Introduction.md` — short overview of Jev and its question types.
- `1-Jev-Beginner.md` — beginner hands-on guide.
- `2-Jev-Developer.md` — guide for developers and data scientists.
- `3-Jev-NeoWork.md` — practice examples using fictional NeoWork data.
- `4-Jev-NeoWork-Advanced.md` — advanced practice combining question types.

The NeoWork examples use fictional data for practice.
